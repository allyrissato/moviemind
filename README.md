# 🎬 MovieMind — Sistema de Recomendação de Filmes

---

# 📌 Sobre o Projeto

O **MovieMind** é um sistema inteligente de recomendação de filmes desenvolvido em Python utilizando Streamlit.

O projeto permite que o usuário pesquise filmes, visualize recomendações personalizadas, explore catálogos e acompanhe métricas através de dashboards interativos.

A aplicação utiliza análise de similaridade entre filmes para sugerir títulos relacionados aos gostos do usuário.

# 🖼️ Interface do Sistema

## 🏠 Tela Inicial

Apresenta o sistema e permite navegar entre as funcionalidades.

---

## ⭐ Recomendações

O usuário seleciona um filme e o sistema retorna recomendações similares.

Exemplo:

* Filme escolhido: *Interstellar*
* Recomendações:

  * Inception
  * The Martian
  * Gravity
  * Arrival

---

## 🎞️ Catálogo

Área destinada para exploração dos filmes disponíveis no sistema.

---

## 📊 Dashboard

Painel com informações e estatísticas dos filmes.

# ⚙️ Como Executar o Projeto

## 1️⃣ Clonar o repositório

```bash

```

---

## 2️⃣ Entrar na pasta

```bash

```

---

## 3️⃣ Instalar dependências


---

## 4️⃣ Executar o sistema

